Predicción de Abandono Estudiantil – Instituto Tecnológico Beltrán 🎓📊

¡Hola! Este repositorio contiene el proyecto final de análisis de datos y machine learning desarrollado de manera colaborativa para predecir y prevenir el abandono escolar en las carreras terciarias del Instituto Tecnológico Beltrán.
Autores

    Equipo de Estudiantes (Demey Gustavo/Fleitas Gonzalo)

Objetivo del Proyecto

Analizar el rendimiento académico del primer año, los factores socioeconómicos y los niveles de asistencia de los estudiantes para entrenar un modelo de Árbol de Decisión. Esto permite a la institución identificar de forma temprana a aquellos alumnos con riesgo de deserción y aplicar estrategias pedagógicas de acompañamiento oportunas.
Estructura del Repositorio

    data/: Contiene los conjuntos de datos históricos de entrenamiento y las tablas finales de evaluación.
    src/: Código fuente en Python (analisis_abandono.py) con la limpieza de datos, entrenamiento del modelo, métricas de evaluación y generación del árbol gráfico.
    outputs/: Resultados gráficos del árbol de decisión y archivos con las predicciones generadas.
    requirements.txt: Librerías y dependencias necesarias (pandas, scikit-learn, matplotlib, etc.).

¿Cómo ejecutar el proyecto?

    Clonar el repositorio y ubicarse en la carpeta principal.
    Instalar las dependencias:

    pip install -r requirements.txt
